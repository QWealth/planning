The signature

Five decisions do almost all the work. Get these right and a page reads as part of this family; get them wrong and no amount of palette-matching rescues it.

DecisionWhy it carries the look
Navy keyline2px on small objects, 3px on cards. One ink colour outlines everything, so it reads as screen-printed rather than bordered.
Hard offset shadow6px 6px 0 with zero blur, in navy. A blurred shadow turns this into generic material design instantly.
Warm paper ground#FFFDF8 on #FBF6EC — never pure white. The warmth is what makes navy read as ink.
Uppercase display typeHeavy face, always uppercase: .02em tracking on headings, .1em on small labels.
Red and tealRed carries primary actions and headings; teal carries focus, success and check state. They never swap jobs.

The shadow rule

Correct

Zero blur, navy, offset down-right.

Wrong

Blurred drop shadow. Same tokens, different family.

/* The one line that defines the look */
box-shadow: 6px 6px 0 var(--cl-navy);

/* Optional depth beneath it — keep the hard edge dominant */
box-shadow: 6px 6px 0 var(--cl-navy), 0 20px 40px rgba(0,0,0,.15);

Video markup

<video class="cl-bg-video"
       src="/bg.mp4" poster="/bg-poster.jpg"

<div class="cl-scrim"></div>

muted and playsinline are both required — without them iOS refuses to autoplay and opens the video fullscreen instead. The poster covers the gap before the first frame decodes.

Substituting the display face

Ultramax Vision is a retro rounded varsity face and is licensed — a desktop licence does not cover serving the file from your domain. Free stand-ins on Google Fonts, closest first: Bowlby One (rounded, chunky — used on this page), Bungee (retro signage), Alfa Slab One (heavy slab), Archivo Black (neutral grotesque).

Pick the fallback from the same category as the real face. This stack originally read "Ultramax Vision", ui-serif, serif. The font file was never bundled, so every heading on the live site silently rendered in Times New Roman — for weeks, because a missing font throws no error. Verify with document.fonts.check('40px "Your Face"') rather than trusting your eyes.

Gotchas

Every one of these cost real debugging time on the live site. They are the most portable thing here — the CSS above you could rewrite in an afternoon; these you would rediscover the hard way.

1 · A flex child refuses to shrink

Symptom
A table card blows past its container instead of scrolling inside it, and the whole page scrolls sideways.
Cause
Flex items default to min-width: auto, so they cannot shrink below their content's intrinsic width. One white-space: nowrap cell holds the entire card open.
Fix
min-width: 0 on the flex child, and as a blanket rule .cl-stack > * { min-width: 0; max-width: 100% }.

2 · A fixed backdrop paints over your content

Symptom
The footer vanishes behind the background video despite appearing later in the DOM.
Cause
position: relative with z-index: auto creates no stacking context. Positioned elements outrank static ones regardless of source order.
Fix
Give anything that must sit above the backdrop an explicit position: relative; z-index: 10.

3 · position: sticky silently does nothing

Symptom
A sticky table header scrolls away with the rows. No error, no warning.
Cause
Sticky needs a scrollport — an ancestor that actually scrolls. With no constrained height the page is the scroller and the header has nothing to stick within.
Fix
Wrap the table in overflow: auto plus a real max-height.

4 · A checkbox collapses into a sliver

Symptom
Fine beside a short label; beside four lines of consent copy it squashes to a 2px stripe.
Cause
As a flex item the box is shrinkable, and width: 18px is only a starting size.
Fix
flex-shrink: 0. Same for icons, avatars and badges beside growing text.

5 · A missing font fails silently

Symptom
Headings render in Times New Roman. Nothing errors; the page just looks "off".
Cause
The font file was never bundled, so the stack fell through — and the declared fallback was a serif.
Fix
Fallbacks in the same category as the real face, and verify with document.fonts.check().

6 · Measuring a block instead of its text

Symptom
You conclude a centred line is about to wrap, shrink it, and it was never close.
Cause
getBoundingClientRect() on a block <p> returns the column width — never the width of the glyphs in it.
Fix
Measure a Range: const r = document.createRange(); r.selectNodeContents(el); r.getClientRects(). Its length is also your true line count.

7 · Filtering full-screen media

Symptom
Scrolling stutters on mobile; screenshot tooling returns blank frames.
Cause
A filter on a fixed, full-viewport video forces a composited layer to be re-filtered every frame.
Fix
Tint with a semi-transparent overlay instead. Same look, none of the per-frame cost.

Adopt it

Four steps, in order. The first two get you most of the way.

#StepDetail
1Paste the tokensOne :root block. Nothing references a hex directly, ever — that discipline is what makes a rebrand cheap later.
2Add the primitivesCard, button, input, alert, table. They're independent; take only what you need.
3Load two facesMontserrat plus a heavy display face, each with a same-category fallback.
4Build the backdropGradient alone, or gradient plus video and scrim. The gradient is the fallback either way.

Keep the cl- prefix or pick your own, but keep a prefix — names like .card and .input will collide with whatever else the page loads.
